WMA MUSIC API v1

Read-only access to the public WMA MUSIC catalogue for distributors, media and partner platforms: published songs, artists, albums, official playlists and new releases. The API never returns audio files or listener data — only public information and links to WMA MUSIC.

FR — Cette API permet aux partenaires de lire automatiquement le catalogue public de WMA MUSIC. Pour obtenir une clé, contactez l'équipe WMA MUSIC.

Authentication

Every request needs an API key, issued by the WMA MUSIC team. Send it in the X-API-Key header (or Authorization: Bearer …). Keep it secret: do not put it in a public web page or app.

curl https://www.wmamusic.net/api/v1/new-releases \
  -H "X-API-Key: wma_YOUR_KEY"

Base URL: https://www.wmamusic.net/api/v1 · Method: GET · Format: JSON (UTF-8) · Each key has an hourly request limit (1,000 by default).

Endpoints

EndpointReturns
GET/tracksPublished songs, newest first
GET/tracks/{id}One song
GET/new-releasesSongs released in the last 7 days (or since since)
GET/artistsArtists with at least one published song
GET/artists/{id}One artist, with their songs
GET/albumsAlbums and EPs
GET/albums/{id}One album, with its songs in order
GET/playlistsOfficial WMA MUSIC playlists
GET/playlists/{id}One playlist, with its songs

Query parameters (lists)

ParameterDescription
limit1–100, default 50
offsetFor paging, default 0
since/tracks and /new-releases: only songs released after this date (ISO 8601, e.g. 2026-11-13, or milliseconds)
artist/tracks: songs of one artist (artist id, main or featured)
genre/tracks: e.g. Gospel
q/tracks: search in titles

Optional fields, when available: isrc, label, producer, songwriter (songs); links (artists). Use url to link listeners to the song on WMA MUSIC.

Terms

Songs, covers and photos remain the property of the artists and rights holders. The API is provided to display and link to WMA MUSIC content; redistributing the content itself requires a separate agreement with WMA UNITED AFRICA. Responses may be cached for up to 60 seconds.
